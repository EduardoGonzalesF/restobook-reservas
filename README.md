# RestoBook — React (Vite)

Sistema de reservas para restaurantes. Proyecto académico — Andrés Eduardo Gonzales Farro.

## Enlaces

- Figma: https://www.figma.com/design/viOQvLRyQ8Wzz0eVOavjMA/RestoBook---EPD
- GitHub: https://github.com/EduardoGonzalesF/restobook-reservas

## Requisitos

Node.js 18+

## Instalación y uso

```bash
npm install
npm run dev
```

Build: `npm run build` · Preview: `npm run preview`

## Funcionalidades

- Wizard de reserva (4 pasos)
- Calendario + disponibilidad
- Admin con modal de eliminación y toasts
- Detección de conflictos mesa/horario
- Persistencia `localStorage`
- Hooks `useState` / `useEffect`

Solo para uso local / entrega académica. No se despliega a Hostinger.
